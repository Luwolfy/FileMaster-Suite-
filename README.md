# FileMaster-Suite-
集成文件管理、图像筛选、GIF播放、分类整理、RPA解密等实用工具的瑞士军刀！

FileMaster Suite 是一套面向日常文件与媒体处理的 Python 工具集合，包含 6 个独立模块，可单独运行，也可通过主控程序统一管理：

主控程序 —— 统一启动器，一键管理所有工具的生命周期
Lens Pro —— 高性能图片筛选与管理器（支持规则过滤、批量导出）
文件管理器 Pro —— 全能文件管理（扫描、过滤、分类、重命名、查重、统计分析）
GIF 自动播放器 —— 专业级 GIF/图片循环播放与预览工具
文件分类工具 —— 基于文件名关键词的智能分类与移动/复制
RPA 批量提取器 —— 解密并提取游戏 .rpa 资源包中的媒体文件

所有工具均采用 Python 编写，界面友好，适合内容创作者、档案管理员、开发者和游戏爱好者。

环境要求
Python 3.7 及以上
支持 Windows / macOS / Linux（部分功能依赖系统命令。

安装依赖
pip install -r requirements.txt

若没有 requirements.txt，请手动安装以下常用库：
pip install pillow pyqt5 tkinterdnd2

对于 RPA 提取器，还需额外安装 unrpa：
pip install unrpa

启动：
  运行主控程序，统一管理所有工具
  python 主控程序.py

  单独运行任一工具
  python Lens\ Pro1.0.py
  python 文件管理器8.3\ 正式版.py
  python 自动播放gif\ -\ 7.0.py
  python 自动提取分类文件夹程序5.0.py
  python 自动提取解密exe媒体.py

主控程序
启动后自动扫描同目录下所有 .py 文件（排除自身）
每个工具以独立行展示，包含名称、状态、启动/停止按钮
支持「全部启动」和「全部停止」批量操作
状态每 1 秒刷新，操作日志记录至 launcher.log

Lens Pro
左侧面板添加文件夹（递归扫描图片）
右侧规则面板添加筛选条件（如 width >= 1920）
中间网格显示缩略图，双击图片打开
底部选择导出路径，执行导出（可复制/移动）

文件管理器 Pro
选择扫描目录，设置深度，开始扫描
在“过滤规则”区域添加白名单/黑名单（支持正则、大小、日期）
点击“应用过滤规则”刷新文件列表
使用“分类文件”、“查找重复”、“批量重命名”等操作
导出结果为 JSON/CSV 供外部分析

GIF 播放器
添加文件夹后自动加载所有 GIF 和静态图片
播放模式：“全部循环”、“顺序播放”、“单曲循环”、“单曲一次”
重复规则：按帧数区间设定重复次数，或按总播放时长
支持速度调节、进度拖动、全屏、收藏夹

文件分类工具
设置源文件夹和目标文件夹
添加分类规则（如文件名包含“风景” → 放入“风景”子文件夹）
点击“预览分类”左侧显示高频词和分类树
确认后点击“开始分类”执行移动/复制（同名自动重命名）

RPA 提取器
点击“添加单个文件夹”或“批量添加”（自动搜索含 .rpa 的子目录）
选择输出目录，勾选是否保留原文件夹结构
点击“开始提取”，工具将调用 unrpa 解密并提取所有资源
扁平化模式会自动处理文件名冲突


配置与自定义
大部分设置（如过滤器规则、播放器速度、重复规则）会自动保存到工具同目录下的配置文件中（如 gif_player_config.txt）
主控程序日志写入 launcher.log
可自行修改各工具的源码以适应特定需求（代码均含中文注释）


常见问题
Q：运行主控程序时提示找不到模块？
A：请确保已安装所有依赖（见上方安装步骤）。若单独运行某工具，也需保证其依赖已安装。

Q：RPA 提取失败，提示“unrpa”命令不存在？
A：请执行 pip install unrpa 安装，并确认 Python Scripts 目录已添加到系统 PATH。

Q：GIF 播放器无法播放某些 GIF？
A：部分 GIF 可能损坏或使用特殊编码，本工具基于 Pillow 读取，若无法打开可尝试用其他软件检查。

Q：文件管理器扫描时卡住？
A：扫描大量文件或深层目录时可能耗时较长，可设置扫描深度限制或启用缓存（“使用缓存”复选框）。

Q：Lens Pro 的规则不生效？
A：请确保规则填写正确，且逻辑关系（AND/OR）选择正确。点击“应用筛选”后才会生效。

Q：能否在 macOS/Linux 上运行？
A：大部分功能支持跨平台，但部分操作（如 os.startfile）在 macOS/Linux 下可能不适用，已通过 subprocess 做了兼容，基本可用。

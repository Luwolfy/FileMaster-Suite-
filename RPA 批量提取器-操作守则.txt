================================================================================
              RPA 批量提取器 - 新手指南
              文件：自动提取解密exe媒体.py
================================================================================

【简介】
RPA 批量提取器用于解密并提取游戏（如 Ren'Py 引擎）中的 .rpa 资源包，
批量导出其中的图片、音频等媒体文件。

【环境要求】
- Python 3.7+
- 必须安装 unrpa 命令行工具：pip install unrpa
- 确保 unrpa 命令可在终端中直接运行（安装后一般自动加入 PATH）

【首次运行】
1. 终端执行：python 自动提取解密exe媒体.py
2. 主窗口包含：
   - 文件夹列表（添加的游戏目录）
   - 输出目录选择
   - 选项（是否保留原结构）
   - 进度条与日志

【使用步骤】

1. 添加游戏文件夹
   - 点击“添加单个文件夹”：手动选择包含 .rpa 文件的目录
   - 点击“批量添加”：选择一个父目录，工具会自动搜索所有包含 .rpa 的子文件夹（通常游戏每个 DLC 或资料片是一个子目录）
   - 文件夹会显示在列表中，支持选中后移除或清空

2. 设置输出目录
   - 点击“浏览…”选择导出目标文件夹（会自动创建）

3. 选择提取选项
   - 勾选“保留原文件夹框架”：会按游戏名创建子目录，并保持 RPA 内部的目录结构
   - 不勾选：所有文件扁平化输出到根目录（同名文件会自动重命名）

4. 开始提取
   - 点击“开始提取”，程序会扫描所有列表中的文件夹，收集所有 .rpa 文件
   - 对每个 .rpa 调用 unrpa 解密，提取到目标目录
   - 进度条显示已处理的 RPA 数量，日志区实时输出每个文件的提取情况

5. 查看结果
   - 提取完成后，目标目录中即为解包后的媒体文件
   - 若选择保留结构，内部路径与 RPA 内部一致

【常见问题】
Q：提示“unrpa 命令不存在”？
A：请确保已执行 pip install unrpa，且 Python Scripts 目录已添加到系统 PATH（可重启终端试试）。

Q：提取失败，返回非零错误码？
A：可能 RPA 文件被加密或损坏，日志中会显示 stderr 信息。

Q：批量添加时没有找到任何 RPA？
A：确认选择的父目录下至少有一级子目录包含 .rpa 文件，程序只搜索一级子目录。

Q：提取后文件很多，如何快速找到想要的内容？
A：可用其他工具（如文件管理器 Pro）进一步过滤。

【小贴士】
- 初次使用建议先添加单个文件夹测试，确认提取正常再批量操作
- 保留结构有助于了解资源组织方式，扁平化便于直接浏览所有文件
- 提取过程可能较慢（尤其是大 RPA），请耐心等待
- 若提取过程中断，可重新运行，已提取的文件不会重复提取（但扁平化模式下可能重命名）

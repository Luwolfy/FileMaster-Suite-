              文件管理器 Pro - 新手指南
              文件：文件管理器8.3 正式版.py
================================================================================

【简介】
文件管理器 Pro 是一款功能全面的文件管理工具，集成了扫描、过滤（白/黑名单）、
批量重命名、文件分类、重复文件查找、深度统计分析和结果导出等功能。

【环境要求】
- Python 3.7+
- 依赖：
    pip install pillow tkinterdnd2
  （注：tkinterdnd2 用于拖放支持，如无法安装可忽略，不影响核心功能）

【首次运行】
1. 终端执行：python 文件管理器8.3\ 正式版.py
2. 主窗口分为左右两部分：
   - 左侧：目录选择、过滤规则、文件操作按钮
   - 右侧：文件列表（树形表格）、统计信息、操作日志

【使用步骤】

1. 扫描文件
   - 点击“选择目录”按钮，选择要扫描的文件夹
   - 设置“扫描深度”（0=无限制，1=仅当前目录，2=包含一级子目录…）
   - 勾选“使用缓存”可加快重复扫描的速度
   - 点击“开始扫描”，进度条会显示扫描进度
   - 扫描完成后，右侧“文件列表”会显示所有文件（含大小、类型、修改时间、相对路径等）

2. 过滤规则（重点）
   - 在左侧“过滤规则”区域，选择规则类型（name、ext、path、size、date）
   - 输入匹配模式（支持普通包含或正则表达式）
   - 勾选“黑名单”表示排除匹配的文件，否则为白名单（保留匹配的）
   - 点击“添加”生成规则，规则会显示在下方列表中
   - 可添加多条规则，先应用白名单（未匹配则排除），再排除黑名单
   - 点击“应用过滤规则”，文件列表会更新为筛选后的结果
   - 规则示例：
       * 保留所有 .txt 文件：type=ext, pattern=.txt, 非黑名单
       * 排除大小 > 100MB 的文件：type=size, pattern=>100M, 黑名单
       * 保留最近7天修改的文件：type=date, pattern=<7d, 非黑名单
       * 使用正则匹配：勾选“正则”，如 \.jpg$ 匹配 jpg 结尾

3. 文件操作（选中文件后执行）
   - 分类文件：按文件类型自动分组，并显示各类的数量和大小
   - 查找重复：按文件名或文件内容（哈希）查找重复文件，可批量删除
   - 批量重命名：支持多步操作（替换、正则、大小写转换、添加前缀/后缀、序号、日期、自定义格式），并可预览
   - 提取/复制：将选中文件复制或移动到目标文件夹，支持保留结构或按类型/日期/大小组织
   - 删除文件：默认移至回收站（桌面上的 FileManager_Trash 文件夹），也可选择永久删除
   - 分析文件：生成深度统计报告（含文件名模式、重复文件等）
   - 导出结果：将扫描结果导出为 JSON 或 CSV 格式，便于外部分析

4. 统计与日志
   - “统计信息”选项卡显示文件总数、大小分布、扩展名排行、修改日期分布等
   - “操作日志”选项卡记录所有操作，方便追溯

【常见问题】
Q：扫描时卡住或进度不更新？
A：如果文件数量极大（数十万），扫描会耗时较长，可设置扫描深度限制或取消“使用缓存”试试。

Q：过滤规则没有生效？
A：请确认规则添加成功（显示在列表中），然后点击“应用过滤规则”。同时检查白名单和黑名单是否冲突。

Q：批量重命名预览与实际不符？
A：预览基于当前文件名和操作顺序，执行时会重新计算序号，请确认操作顺序正确。

Q：重复文件查找速度慢？
A：按哈希查找需要读取文件内容，大文件会慢。建议先按名称快速筛选，再对疑似重复的按哈希确认。

【小贴士】
- 使用“正则”时，可参考 Python 正则语法（如 \d+ 匹配数字）
- “自定义格式”重命名支持占位符：{name}, {ext}, {index}, {date:%Y-%m-%d}, {left:N}, {right:N}, {mid:start,len}
- 分析报告可保存为文本文件，便于归档

================================================================================
                  Lens Pro 图片筛选器 - 新手指南
                  文件：Lens Pro1.0.py
================================================================================

【简介】
Lens Pro 是一款基于 PyQt5 的高性能图片浏览与管理工具，支持多文件夹扫描、
自定义规则筛选、缩略图异步加载和批量导出。

【环境要求】
- Python 3.7+
- 安装依赖：
    pip install pyqt5 pillow

【首次运行】
1. 终端执行：python Lens\ Pro1.0.py
2. 主窗口分为三栏：
   - 左侧：文件夹列表
   - 中间：缩略图网格视图
   - 右侧：筛选规则面板

【核心使用流程】

1. 添加图片文件夹
   - 点击左侧的“+ 添加”按钮，或菜单“文件” → “添加文件夹”
   - 选择包含图片的目录（会自动递归扫描所有子文件夹）
   - 文件夹会出现在列表中，同时自动开始扫描图片
   - 扫描过程中，中间区域会逐步显示缩略图（异步加载，不卡顿）

2. 浏览与查看图片
   - 缩略图显示图片预览，鼠标悬停可看到尺寸、大小等信息（工具提示）
   - 双击任意缩略图，系统默认程序打开该图片（用于查看原图）
   - 右键点击缩略图可进行简单操作（如复制路径等，视系统支持）

3. 筛选图片（核心功能）
   - 在右侧“筛选规则”面板，点击“添加规则”
   - 选择规则类型（如 orientation、width、height、megapixels、aspect_ratio、file_size、extension、filename、date_modified 等）
   - 设置操作符和值（例如 width >= 1920）
   - 可添加多条规则，并通过“AND（且）”或“OR（或）”组合
   - 点击“应用筛选”，中间视图会实时更新为符合规则的图片
   - 规则示例：
       - 筛选横屏图片：orientation is landscape
       - 筛选大于 5MP 的图片：megapixels >= 5
       - 筛选最近一个月修改的图片：date_modified after 30d
       - 筛选 JPEG 或 PNG：extension in .jpg,.png

4. 导出筛选结果
   - 在底部“导出到”输入框中填写目标文件夹，或点击“浏览...”选择
   - 点击“导出”按钮，弹出对话框选择：
       * 目录结构：平铺（所有文件放到根目录）或保留原相对路径
       * 操作方式：复制（保留原文件）或移动（删除原文件）
   - 点击确定，开始导出，进度条显示进度

【高级功能】
- 收藏夹：可将常用文件夹添加到收藏（暂无，后续扩展）
- 导出时自动处理同名冲突（重命名或跳过）

【常见问题】
Q：添加文件夹后没有显示缩略图？
A：检查文件夹内是否有支持的图片格式（.jpg/.png/.gif/.webp 等）。若图片很大，加载需要时间。

Q：规则筛选后没有结果？
A：检查规则条件是否正确，比如数值单位是否正确（像素、MB等）。逻辑关系（AND/OR）要符合预期。

Q：导出时提示“目标文件夹不存在”？
A：请先确保目标路径有效，或点击“浏览”重新选择。

Q：能否同时筛选多个文件夹？
A：可以，左侧可添加多个文件夹，所有图片会合并显示。

【小贴士】
- 缩略图缓存会占用内存，若图片数量巨大，可适当调整 THUMBNAIL_SIZE（代码中常量）
- 使用“日期”规则时，支持相对时间（如 30d 表示最近30天，6m 表示6个月前）
- 导出时选择“保留目录结构”有助于保持原有组织方式。

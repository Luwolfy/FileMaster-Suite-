================================================================================
              GIF 自动播放器 - 新手指南
              文件：自动播放gif - 7.0.py
================================================================================

【简介】
GIF 自动播放器是一款专业级的 GIF/图片循环播放与预览工具，支持文件夹加载、
多种播放模式、速度调节、重复规则定制、全屏显示和收藏夹。

【环境要求】
- Python 3.7+
- 依赖：pip install pillow

【首次运行】
1. 终端执行：python 自动播放gif\ -\ 7.0.py
2. 主窗口包含：
   - 顶部控制栏：添加文件夹、播放控制、模式选择、速度调节、图片停留时间
   - 中部画布：显示当前帧/图片
   - 底部：进度条、播放列表、状态信息

【使用步骤】

1. 添加文件
   - 点击“添加文件夹”，选择包含 GIF 或静态图片（.png/.jpg 等）的目录
   - 勾选“包含子文件夹”可递归扫描
   - 文件会出现在底部的播放列表中

2. 播放控制
   - ▶ 播放：开始播放当前选中的文件
   - ⏸ 暂停：暂停播放
   - ■ 停止：停止播放并回到第一帧
   - ◀◀ / ▶▶：切换到上一个/下一个文件
   - 跳转：输入序号并点击“跳转”即可跳转到指定文件

3. 播放模式（重要）
   - 全部循环（loop_all）：所有文件依次播放，结束后从头开始
   - 顺序播放（sequential）：所有文件依次播放，结束后停止
   - 单曲循环（single_loop）：当前文件不断循环
   - 单曲一次（single_once）：当前文件播放一次后停止

4. 重复规则（针对单个文件的内部循环）
   - 按帧数区间：设定帧数范围对应的重复次数（如 1-10 帧重复 6 次，11-26 帧重复 4 次）
   - 按时间长度：设定最小播放秒数，不足则重复播放直到达到该时长
   - 可在界面中自由添加/删除规则

5. 速度与进度
   - 拖动“速度”滑块可加快或减慢播放速度（0.25x ~ 4.0x）
   - 进度条可拖拽跳转到任意帧位置
   - 顶部显示当前帧/总帧数、累计播放时间

6. 全屏与收藏
   - 点击“全屏”按钮或按 F11 可进入全屏模式
   - 按 Ctrl+F 可将当前文件加入收藏夹，方便快速访问
   - 在“收藏”菜单中可管理收藏的文件

7. 静态图片处理
   - 对于非 GIF 图片（如 JPG/PNG），会作为单帧显示
   - 可在控制栏设置“图片停留秒数”（默认 3 秒），调整观看时长

【常见问题】
Q：添加文件夹后列表中有文件但画布无显示？
A：可能是文件正在后台加载，稍等片刻；或文件格式不支持（常见格式均支持）。

Q：播放时画面卡顿或不同步？
A：如果 GIF 帧数很多，可降低速度或关闭“显示帧/时间叠加”以减轻负担。

Q：重复规则不生效？
A：规则仅对当前文件生效，且需在播放前设置。规则会保存到配置文件。

Q：全屏后如何退出？
A：按 Esc 键或再次点击“全屏”按钮。

【小贴士】
- “图片停留时间”对 GIF 无效，仅对静态图片有效
- 收藏夹保存的是文件绝对路径，若文件被移动则无法打开
- 预加载机制会提前加载后两个文件，使切换更流畅
